# Contact prediction v2

This version corrects the main target flaw in the first model. The first model predicted a future TTC threshold event even though current TTC was an input. V2 predicts future simulated bumper contact, which is a distinct outcome in this toy simulator.

## Dataset

- 700 episodes: 100 for each of seven scenario families.
- 58,310 trajectory rows; 221 episodes end in simulated contact.
- Contact is interpolated inside a 0.1-second step and the episode ends at the first contact.
- Rows without a complete 3-second future window are excluded unless contact is observed in the window.
- Data are generated by the project's one-dimensional simulator; there are no real driving records.

## Rebuild

```powershell
python scripts/generate_phase2.py --config config/phase2_contact_v2.json --out-dir data/contact_v2/phase2
python scripts/preprocess_phase3.py --input data/contact_v2/phase2/trajectories.csv --out-dir data/contact_v2/phase3
python scripts/label_phase4.py --input data/contact_v2/phase3/trajectories_features.csv --out-dir data/contact_v2/phase4
python scripts/train_contact_model_v2.py
python scripts/predict_contact_model_v2.py --input data/contact_v2/phase3/trajectories_features.csv --output data/contact_v2/model/predictions.csv
```

The training script groups splits by episode (424 train, 107 validation, 67 calibration, 102 test), compares logistic regression, random forest, and histogram gradient boosting on validation average precision, calibrates the selected model separately, then evaluates once on the held-out test episodes. Model inputs include current state and one-second past changes; target and future values are not inputs.

## Results and limits

Random forest was selected. On the test set, average precision was 0.991, recall was 0.966, precision was 0.893, and Brier score was 0.009 at a threshold selected on validation data. The current TTC ≤ 3-second rule reached average precision 0.881 and recall 0.903 on the same test rows.

These are synthetic simulator results, not estimates of real crash risk. Test episodes share the same seven scenario families as training. This model is not suitable for use in a vehicle. Validate against an independent, trusted simulator or observed driving data, including scenarios and conditions withheld from training, before making safety claims.

See `model/model_card.md`, `model/evaluation.json`, `model/episode_splits.json`, and `model/test_predictions.csv` for details and auditable predictions.
