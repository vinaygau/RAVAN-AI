# Phase 2 Dataset

`trajectories.csv` is a reproducible, synthetic pilot generated by `scripts/generate_phase2.py` from `config/phase2.json`. It contains 140 episodes (20 each for S1–S7), sampled at 10 Hz until the configured end time or first sampled contact. `metadata.json` records the base and per-episode seeds, all sampled episode parameters, episode outcomes, and summary statistics. `quality_report.md` summarizes coverage, feature validity, and limitations.

The data is a one-dimensional scripted kinematic simulation. It is not real-world or CARLA data. Scenario IDs identify generation setups only; no hazard labels are included. The provisional ranges and equations are documented in the Phase 1 specification.

Regenerate from the project root with:

```powershell
python scripts/generate_phase2.py
```
